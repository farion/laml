# LAML 1.17.7

## Standalone desktop applications

- Run the CLI and native editor from their individual executables, with fonts, icons, logos, help and license notices embedded. Remove redundant runtime asset directories from CLI release archives.
- Check for editor updates in **Settings → Updates**, explicitly install the selected release with SHA-256 verification, then close and restart the editor. Windows completes replacement after exit.
- Install the CLI matching the running editor through **Settings → CLI** into the user account. Confirm existing-file replacement and show PATH guidance when needed.
- Keep update and local-install settings out of browser builds. Retain the CLI's explicit `laml update` command.

## Diagram interaction

- Rebuild sequence interactions around compiler geometry and atomic source edits: participant insertion/reordering, message creation and reconnection, activation resizing, destruction markers and contextual insertion menus.
- Support independent activation markers at both message ends and symbolic alignment between message occurrences and activation boundaries.
- Extend shared graph interaction with contour docks, contextual insertion, endpoint reconnection and clearer drag feedback.
- Insert into empty containers, transfer elements between container bodies and drag nested nodes back to root while preserving applicable authored constraints.
- Improve visible-element picking, inline fragment editing, hover retention and insertion-menu icon alignment.

## Source editing and responsive workspace

- Add role-based syntax highlighting, contextual completion, construct templates and bracket/quote pairing, with local handling of incomplete source.
- Improve source clipboard behavior over ordinary HTTP, contextual clipboard actions, fixed line-number gutters and scrollbar placement.
- Adapt narrow workspaces with a Source/Diagram selector, Properties flyout, grouped action menus, scrolling tabs and touch-visible controls.
- Refine error toasts and About branding; keep English and German UI text aligned.

## Shared compiler routing

- Search logical obstacle corridors before concrete coordinate variants, reuse valid route prefixes and retain exhaustive fallback, hard constraints and collision protection.
- Repair parallel diamond endpoints, relations to enclosing container frames and self-loop allocation order.
- Route nested sequence self-calls through appropriate inner/outer corridors and expose their actual rendered geometry for picking.

Includes matching compiler/editor packages, browser assets and the complete Linux amd64 Docker Compose server bundle.
