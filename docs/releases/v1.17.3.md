# LAML 1.17.3

## Editor language

- Add English and German interface languages to the native and browser editor, including dialogs, tooltips, the file library and browser startup messages.
- Add **Settings → Language** before Theming, with **Auto** (default), **English** and **German**. Auto detects browser preferences or the native system locale, using English as the fallback.
- Save the language choice locally and apply it immediately without changing document source, undo history or diagram rendering. Keep notation terminology in English where translation would be ambiguous, and retain original compiler diagnostic details.
- Use **Download LAML auf deinen PC/MAC** for the German titlebar download button.

## Editor refinements

- Move About into its own titlebar dialog, with Imprint and Data Privacy Statement accessible there.
- Add a compact platform-aware download chooser for the graphical editor and CLI, with versioned asset links and access to other releases.
- Align the empty workspace background with the titlebar, refine the library navigation and show the LAML wordmark on the browser loading page.

Includes matching compiler/editor packages, browser assets and the complete Linux amd64 Docker Compose server bundle.
