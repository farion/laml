# LAML 1.17.6

## Inline text editing

- Double-click editable diagram text to edit it in place, including node labels, arrow captions and sequence message labels.
- Confirm with Enter or by clicking outside; Escape discards the draft. Shift+Enter inserts a newline where the notation supports it.
- Apply confirmed edits to the `.laml` source as one compiler-checked undo step, preserving IDs and connection endpoints. Retain drafts when validation fails and reject stale edits.

## Connection gestures

- Use the four edge-arrow grips without an extra automatic-side button inside nodes.
- Hold Shift when pressing a grip for an automatic source side, and independently hold Shift when releasing for an automatic target side. Without Shift, the respective side is fixed.
- Explain both gestures in the grip's hover text and update the drag preview for the current target-side choice. Preserve explicit named port endpoints.

## Download hint

- Add a localized “Now with MCP” caption and an intermittently animated arrow beside the binary-download button.
- Hide the hint when it would overlap the centered LAML Editor title.
