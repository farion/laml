# LAML 1.17.0

## Editor

The native and browser editor now supports Generic node-edge diagrams, all
compiler-supported UML diagram types, BPMN and C4. Source remains authoritative;
visual edits are compiler-checked source transactions with shared undo/redo.

- Diagram-specific creation, properties and structural editing.
- Direct sequence participant/event dragging, activation resizing and endpoint
  docking; contextual sequence and BPMN authoring controls.
- Separate Auto/Dark/Light editor appearance and document-driven preview themes.
- Improved recovery workflow, onboarding and context menus.
- Incremental route reuse for applicable relation appearance changes.

## Browser hosting and Docker Compose

`laml-ui serve` defaults to browser-local document storage. Documents autosave to
IndexedDB, including invalid or incomplete text; imports, source downloads,
SVG/PNG/PDF exports and a browser library are included. The server processes
complete requests transiently without persisting user documents. The default
session limit is ten browser sessions. Explicit `--workspace` retains file-based
hosting.

For Linux x86-64, download `laml-server-v1.17.0-linux-amd64.tar.gz` and
`SHA256SUMS`. Verify and extract the archive, then run:

```sh
docker compose up -d --build
```

The package contains prebuilt CLI and host binaries, matching browser assets,
Dockerfile, Compose configuration and license notices. The server only assembles
the runtime image; no Rust toolchain is required. Deployment values live directly
in `compose.yaml`. See its bundled README for port configuration and upgrades.

## Compiler and distribution

- Shared routing and label association improvements, including BPMN label-aware
  detours and source-backed sequence activation/destruction alignment.
- One `vVERSION` tag builds both applications for Linux x86-64, macOS Intel/ARM
  and Windows x86-64, plus browser assets and the Linux amd64 server bundle.
- The release includes corresponding source and SHA-256 checksums.
- Compiler license: MIT. Editor license: GPL-3.0-or-later.

Browser documents remain local to a browser profile and site origin. Download
`.laml` backups before clearing site data, and preserve the public origin when
upgrading. The server has no built-in login; use the deployment's firewall and
HTTPS reverse proxy as appropriate.
