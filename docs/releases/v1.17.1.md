# LAML 1.17.1

## Editor

- Explicit file creation and an empty workspace with New/Open actions.
- Editable starter examples for all 20 diagram types, with an optional empty scaffold.
- Compact browser document library with search, Documents/Trash views and modal deletion confirmation.
- Refined recovery, onboarding, theme handling and notation-specific editing.
- Fixes for BPMN inline-flow insertion, template editing, reversed dashed arrows and zoom controls in narrow panes.
- New LAML vector wordmark in the README, onboarding and empty workspace, with light/dark variants and an L favicon.
- Help links to the supplied Imprint and Data Privacy Statement.

## Compiler and verification

- Corrected sequence fragment validation for destruction alignment.
- Updated routing, documentation and editor regression expectations to match delivered behavior.
- Eight long-running audits remain available for explicit manual execution with `--ignored`.
- Full local verification before the branding changes: 873 passed, zero failed and eight ignored; formatting and Clippy passed. Native/WASM debug builds and focused browser branding checks also passed after the branding changes.

## Distribution

The unified release builds CLI and editor archives for Linux x86-64, macOS Intel/ARM and Windows x86-64, browser assets, corresponding source and SHA-256 checksums.

For a Linux amd64 server, use `laml-server-v1.17.1-linux-amd64.tar.gz`. It includes prebuilt binaries, matching browser assets, Dockerfile, `compose.yaml` and license notices. Extract the full archive, then run:

```sh
docker compose up -d --build
```

No Rust compilation is required on the server. Docker assembles the runtime image locally; documents remain in each visitor's browser by default.
