# LAML visual identity

The wordmark was designed from an OpenArt / Recraft V4.1 vector concept on November 15, 2026. `openart-original.svg` preserves that original output. Production artwork regularizes the contours, spacing and L-to-node connection for small-screen clarity.

- `../images/laml-logo.svg`: transparent wordmark for light backgrounds.
- `../images/laml-logo-dark.svg`: transparent wordmark for dark backgrounds.
- `../../crates/laml-ui/assets/favicon.svg`: simplified first L and terminal node, on a fixed graphite tile for readable browser tabs.
- PNG and ICO fallbacks are rendered from the favicon SVG.

Production SVGs contain only vector shapes, with no embedded raster images, external fonts or network dependencies. The editor embeds the same wordmarks used by the README.
