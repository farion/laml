# v1.3 implementation status — not release-ready

Do not update Cargo version, tag, push or publish a v1.3 release until every release criterion below has a tested implementation. This file is an implementation checkpoint, not user documentation. The full agreed target is in [the graph/UML design](gne-class-object-v2-design.md). The existing language reference continues to describe only working behavior.

## Implemented and tested in the current working tree

- `//` source comments replace `#` across `.laml`, `.lamlstyle`, examples, tests and relevant docs; `https://` in unquoted text is preserved. `#` is no longer consumed as a comment.
- `style-classes=` replaces `classes=` in graph and sequence parsing, examples, tests and docs.
- GNE named relation `@id` syntax is accepted; old `name:` syntax still works as a temporary compatibility path until graph and sequence migration is complete.
- LSS universal `*` selector is available at the lowest precedence.
- Graph `type: class|object` parsing, basic class/interface/enum/datatype/object nodes, source-ordered body rows and dividers, class attribute/operation compartment checks, object slots, basic folded one-line notes with dotted node/member attachment; globally explicit member-to-member edge attachments; undirected `--` plus the first checked UML operators (`-->`, `..>`, `--|>`, `..|>`, `*--`, `o--` and combinations); object diagrams reject class-only operators; basic UML multiplicities and roles at association ends are parsed, validated and collision-checked; selectable SVG body text, object underlining, enum/interface/datatype headings, PNG/PDF export from the same SVG, and undirected soft adjacency are present. See `tests/class_object_v13.rs` and the working drafts in `docs/drafts/`.
- Preexisting sequence and graph tests remain passing. Strict Clippy and rustfmt pass; actual release validation must be rerun after all changes.

## Open before v1.3 can be claimed complete

- Finish the agreed ID model across all declaration kinds and sequence references, including globally unique explicit `@id`, scoped defaults, unambiguous single-target resolution, and styling classes independent from IDs.
- Implement node containers/qualified references, true ports, member and edge anchors, n-ary association junctions, qualifiers, multiline notes and note-to-edge links, association classes, complete UML association-end semantics (visibility, qualifiers and explicit end-label placement), precise marker clearance/routing, stereotypes and full UML-specific validation for the now visible generalization, realization, dependency, navigability and whole/part diamonds. Do not mistake an implemented glyph for complete UML validation.
- Implement complete GNE node shapes with visible-outline ports and routing, mandatory side and end-label layout rules, visibility/abstract/static formatting with consistent font metrics and selectable text in SVG/PDF, member and contextual LSS selectors, safe explicit hiding, icon styling, conditional Phosphor attribution in SVG/PNG/PDF metadata.
- Implement anonymous typed objects, local binding validation and audited UML `<<bind>>` notation, package/enum/datatype special rules, lollipop eligibility, object-link validation and UML restrictions. Audit normative ambiguities (including mixed class/instance diagrams) before claiming standard compliance.
- Change all *published* v1.3 examples to built/tested sources, add generated preview images and README references, update `docs/language-reference.md`, language contract, and user guides to exactly the shipped implementation. Add positive/negative end-to-end tests for all agreed constructs and check all four CI targets.
- Only after complete local validation: bump version to `1.3.0`, commit, push from an authenticated shell when explicitly confirmed, verify four-platform CI, then tag/release and confirm assets. No remote publication has been attempted.
