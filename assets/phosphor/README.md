# Vendored Phosphor Icons

Source: `phosphor-icons/core` at commit `2b75f3ad12b420c9504ef05df8d2564a28f8500e` (https://github.com/phosphor-icons/core).

Included unmodified regular-weight SVGs: `folder`, `lock`, `globe`, `shield`, `package`, `user`, `database`. The accompanying upstream MIT license is `LICENSE` in this directory. The exported SVG paths are scaled by LAML, not sourced from a font or remote service.

When an actual icon is rendered, LAML writes the exact notice into nonvisible SVG `<metadata>`, PNG `iTXt` (`License`), and PDF document `Info.Subject`. Exports without icons have none of those Phosphor notices. This is an engineering attribution policy; legal review is required before publication.
